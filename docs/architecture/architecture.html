Voltage extraction

Every cross-module call in the algorithm goes through pipeline.process_fov; inside each module the functions form a tree. So the figure that shows the mechanism is the dataflow through the orchestrator: each box is one stage call, each arrow carries the array that stage hands on, and the shape beside it comes from that function's docstring. Two branches leave the raw movie. The reference branch uses the first n_ref frames to build the sharpened image that segmentation runs on; the movie branch is background-subtracted and motion-corrected in place. They rejoin at footprint extraction, and the pseudoinverse turns footprints into traces.

QC checks

The post-hoc SNR pass never re-runs the extraction and no stage calls another: each script reads files the previous one left on disk and writes its own beside them. The coupling to the package is two imports, the .mat reader in pyali.io and the SNR definitions in pyali.metrics. The figure therefore shows scripts and the files between them.
